SoundPadEZ

Простой саундпад для Windows: воспроизводит аудио из файлов в голосовой чат и в наушники.

Скачать и запустить

1. Скачайте ZIP из последнего релиза (https://github.com/timanovdd-arch/SoundPadEZ/releases/latest) и распакуйте в отдельную папку.
2. Установите VB-CABLE с официального сайта (https://vb-audio.com/Cable/). Запускайте установщик от администратора; если он попросит, перезагрузите Windows. Драйвер не входит в комплект программы.
3. Запустите Soundpad.exe. Складывайте файлы в папку sounds рядом с EXE. Список обновляется автоматически.

Приложение собрано со средой .NET внутри: отдельно устанавливать .NET для готового EXE не требуется. Поддерживается Windows x64.

Какие устройства где выбрать

Схема передачи: ваш микрофон → SoundPadEZ, где добавляется звук файла → CABLE Input → CABLE Output → Discord. В наушниках файл воспроизводится отдельно. Названия Input и Output относятся к виртуальному кабелю: программа отправляет звук в его Input, а Discord забирает готовую смесь из Output.

| Где | Что выбрать |
| --- | --- |
| SoundPadEZ → Микрофон | Ваш настоящий микрофон либо «Микрофон (NVIDIA Broadcast)» |
| SoundPadEZ → Вывод звука | CABLE Input (VB-Audio Virtual Cable) |
| Discord / игра → Микрофон | CABLE Output (VB-Audio Virtual Cable) |
| Windows → Система → Звук → Вывод | Ваши обычные наушники; через них программа даёт прослушать файл |
| Windows → Система → Звук → Ввод | Можно оставить настоящий микрофон: для этой схемы менять стандартный ввод не требуется |
| Discord → Голос и видео → Устройство вывода | Ваши обычные наушники |

Например, если у вас USB-гарнитура, выберите её микрофон в SoundPadEZ, а её наушники — в выводе Windows и Discord. Устройства Realtek, USB Audio и другие называются по-разному: выбирайте именно то, которым пользуетесь.

Первый запуск

1. Установите VB-CABLE, затем запустите SoundPadEZ. Если программа была открыта при установке драйвера, нажмите «Обновить устройства». Если кабель не появился, перезагрузите Windows.
2. В поле «Микрофон» выберите свой настоящий микрофон. CABLE Output здесь выбирать нельзя: это вернёт готовую смесь обратно в программу.
3. В поле «Вывод звука» выберите CABLE Input (VB-Audio Virtual Cable). Это вывод в голосовой чат, а не выбор наушников.
4. Включите «Добавлять мой голос». Дождитесь «Подключено». При разговоре должен меняться индикатор «Голос: N%». Если подключения нет, нажмите «Подключить» и прочитайте сообщение внизу окна.
5. В Discord откройте Настройки пользователя → Голос и видео. Явно выберите CABLE Output (VB-Audio Virtual Cable) устройством ввода и свои наушники устройством вывода. Пункт «По умолчанию» для ввода лучше не использовать: он может остаться привязан к обычному микрофону.
6. Положите MP3, WAV или другой поддерживаемый файл в sounds, выберите его и нажмите «Играть». Файл должен быть слышен у вас и в голосовом чате. «Только у себя» проверяет лишь прослушивание и не отправляет файл собеседникам.
7. Во время длинного файла нажмите Ctrl+Alt+C: файл должен остановиться у вас и у собеседников, а ваш голос — продолжить передаваться. Повторите проверку со свёрнутым окном программы.

Оставьте «Добавлять мой голос» включённым. Передача голоса подключается автоматически при запуске. Пока CABLE Output выбран микрофоном в голосовом чате, держите SoundPadEZ открытым. После закрытия программы верните обычный микрофон в настройках чата.

Программа не меняет стандартные устройства Windows и настройки Discord.

Не назначайте CABLE Input стандартным выводом Windows: иначе системные звуки могут попасть в голосовой чат, а локальное прослушивание не заработает. Для обычной схемы также не нужно включать «Прослушивать с данного устройства» в свойствах микрофона или кабеля.

Discord: чтобы шумоподавление не съедало саунды

Discord получает из CABLE Output один общий сигнал: голос + файл. Фильтр после смешивания обрабатывает оба источника. Поэтому для SoundPadEZ рекомендуем начать с таких настроек в «Голос и видео»; названия и расположение пунктов могут различаться между версиями Discord:

| Параметр Discord | Что поставить для проверки |
| --- | --- |
| Устройство ввода | CABLE Output (VB-Audio Virtual Cable) |
| Устройство вывода | Ваши наушники |
| Шумоподавление / Noise Suppression | Нет / None: отключить и Krisp, и стандартный вариант |
| Эхоподавление / Echo Cancellation | Отключить при работе в наушниках, если оно искажает файл |
| Автоматическая регулировка усиления / Automatic Gain Control | Отключить для начала проверки, чтобы уровень файла не менялся автоматически |
| Автоматическое определение чувствительности | При обрезании тихих фрагментов отключить и настроить порог вручную |

Это рекомендуемый режим для передачи файлов, а не гарантия одинакового звучания в любом канале. Krisp предназначен для удаления посторонних звуков; в этой схеме он может подавлять музыку и эффекты вместе с шумом. Сам SoundPadEZ не отключает настройки Discord. См. описание Krisp (https://support.discord.com/hc/en-us/articles/360040843952-Krisp-FAQ) и официальную диагностику звука Discord (https://support.discord.com/hc/en-us/articles/360045138471-Discord-Voice-and-Video-Troubleshooting-Guide).

Активация по голосу: запустите тихий фрагмент файла и настройте порог так, чтобы Discord передавал его даже без вашей речи. Если индикатор передачи гаснет, порог слишком высокий. При низком пороге в чат может проходить и фоновый шум микрофона.

Рация / Push-to-Talk: удерживайте назначенную в Discord кнопку передачи всё время, пока должен звучать файл. Хоткей SoundPadEZ запускает файл, но не нажимает рацию Discord. Подробности — в инструкции по режимам ввода Discord (https://support.discord.com/hc/en-us/articles/211376518-Voice-Input-Modes-101-Push-to-Talk-Voice-Activated).

Начните с невысокой громкости файла и попросите собеседника оценить баланс с голосом. Ползунок SoundPadEZ меняет только файл. Громкость входа Discord влияет уже на общую смесь. Если голос и файл вместе хрипят, уменьшите уровень файла или усиление настоящего микрофона.

Если нужен чистый голос и целые саунды: NVIDIA Broadcast

Если NVIDIA Broadcast поддерживается вашим компьютером, шум можно убирать до смешивания:

1. В NVIDIA Broadcast выберите источником свой настоящий микрофон и включите удаление шума / Noise Removal. CABLE Output источником не выбирайте.
2. В SoundPadEZ выберите Микрофон (NVIDIA Broadcast) вместо настоящего микрофона. «Добавлять мой голос» оставьте включённым, вывод — CABLE Input.
3. В Discord вводом по-прежнему должен быть CABLE Output, выводом — наушники. Если выбрать Broadcast напрямую в Discord, до чата дойдёт голос без файлов SoundPadEZ.
4. Отключите повторное шумоподавление Discord. Держите Broadcast и SoundPadEZ открытыми.

Получится: настоящий микрофон → шумоподавление Broadcast → SoundPadEZ добавляет файл → кабель → Discord. Такой порядок оставляет файл вне фильтра Broadcast. NVIDIA также рекомендует избегать повторной обработки одинаковыми эффектами: официальная настройка Broadcast (https://www.nvidia.com/en-us/geforce/guides/broadcast-app-setup-guide/).

Без Broadcast используйте настоящий микрофон в SoundPadEZ и отключённый шумоподавитель Discord. При этом фон комнаты тоже попадёт в смесь; для контроля передачи можно использовать рацию.

Если что-то не работает

| Симптом | Что проверить |
| --- | --- |
| У себя слышно, собеседник файл не слышит | Ввод Discord должен быть CABLE Output. Используйте «Играть», а не «Только у себя»; проверьте mute, рацию, чувствительность и шумоподавление |
| Саунды слышно, голос не слышно | В SoundPadEZ включите «Добавлять мой голос», выберите настоящий микрофон или Broadcast и проверьте индикатор голоса. Для Broadcast проверьте источник и запуск приложения |
| Голос слышно, саунды нет | Убедитесь, что Discord слушает CABLE Output, а не настоящий микрофон/Broadcast напрямую. Проверьте громкость файла и фильтры Discord |
| Собеседник слышит, а в наушниках файла нет | Стандартный вывод Windows должен быть вашими наушниками. После его смены заново запустите файл |
| Музыка обрывается или слышна только во время речи | Отключите шумоподавление, настройте чувствительность или удерживайте рацию; затем проверьте эхоподавление и автоусиление |
| Эхо, свист или дублирование | Используйте наушники. Не выбирайте CABLE Output микрофоном SoundPadEZ/Broadcast и отключите лишнее «Прослушивать с данного устройства» |
| Нет CABLE Input / CABLE Output | Установите официальный VB-CABLE, обновите устройства; при необходимости перезагрузите Windows. См. схему работы кабеля (https://vb-audio.com/Cable/) |
| Ctrl+Alt+C не срабатывает | Закройте вторую копию SoundPadEZ и проверьте сообщение о занятых сочетаниях внизу окна. Сочетание фиксированное, назначать его файлу не нужно |
| После закрытия программы пропал голос в Discord | Верните настоящий микрофон или Broadcast в устройстве ввода Discord: закрытая программа больше не передаёт голос в кабель |

В завершение проверьте три действия с собеседником: речь без файла, файл без речи, остановку по Ctrl+Alt+C с продолжающейся речью. Это проверяет весь путь до чата; локальное прослушивание проверяет только наушники.

Управление

- «Играть», Enter или двойной щелчок: один раз воспроизвести выбранный файл в микрофон и наушники. После окончания файл останавливается; голос продолжает передаваться.
- «Стоп» или Ctrl+Alt+C: остановить файл в микрофоне и наушниках, сохранив передачу голоса. Хоткей работает и при свёрнутом окне.
- «Только у себя»: прослушать файл только в наушниках.
- Ползунок громкости регулирует файл, не меняя уровень голоса.
- Поддерживаются MP4, MP3, WAV, M4A, AAC, WMA и AIFF. Для MP4 используется аудиодорожка и декодеры Windows; необычные кодеки могут потребовать конвертации.

Хоткеи

Пять глобальных сочетаний для запуска: Ctrl+Alt+1…5. Выберите файл, затем сочетание и нажмите «Назначить выбранному звуку». «Очистить» снимает назначение. Ctrl+Alt+C — отдельная фиксированная команда остановки, назначение ей не требуется. Хоткеи работают при свёрнутом окне; удержание клавиш не повторяет звук. Если сочетание занято другой программой, приложение сообщает об этом.

Избранное

Выберите файл и нажмите «★ В избранное». В категории «★ Избранное» отображаются только отмеченные файлы. Удаление из избранного не удаляет сам файл.

Настройки, избранное и назначения сохраняются локально в settings.json рядом с EXE. Личные звуки и настройки не входят в репозиторий или релиз.

Сборка из исходников

Нужны Windows и .NET 9 SDK:

``powershell
dotnet publish src/SimpleSoundpad.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o build-release
`

Положите собранный Soundpad.exe в отдельную папку и создайте рядом папку sounds (приложение также создаёт её само).

Диагностические команды записывают результат рядом с EXE:

`powershell
.\Soundpad.exe --check
.\Soundpad.exe --hotkey-check
.\Soundpad.exe --library-check
`

Перед --hotkey-check закройте обычное окно приложения, чтобы сочетания были свободны. Проверка --library-check использует временную папку и не меняет личные настройки. --check проверяет доступные устройства и чтение файлов из sounds`.
